# Inverse Square Lab 3D

A Vercel-ready React/Vite simulation for AQA A-level Physics Required Practical 12.

## Features
- Interactive 3D virtual laboratory with movable detector, metre track, source holder and scaler
- Inverse-square count-rate model with background count and Poisson-style random variation
- Guided Practical, Investigation Mode and Challenge Mode
- Prediction task before measurement
- Results table with r, r², 1/r², raw count rate, background correction and uncertainty
- Graphing and linear regression for corrected rate vs 1/r²
- Theory section, uncertainty/calculation coach and auto-marked assessment
- Teacher controls for background level, statistical noise and regression visibility
- CSV export

## Safety scope
This is a simulation-only learning resource. It intentionally does not provide instructions for handling real radioactive sources.

## Deploy to Vercel
Import the project into Vercel. Vercel should detect Vite automatically. The included vercel.json sets the build command and output directory.
